# HR System

## Overview
A web-based HR management application built with Angular that allows users to manage employee information through a modern, responsive interface.

## Features
- Employee directory
- Employee profile pages
- Scheduling views
- Client-side routing
- Responsive UI built with Angular and SCSS

## Technologies
- Angular
- TypeScript
- SCSS
- HTML

## What I Learned
- Building reusable Angular components
- Implementing client-side routing
- Organizing a scalable front-end project
- Designing user-friendly interfaces

## Future Improvements

- Database support
